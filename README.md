# Advanced Optimization Core (AOC)

Advanced Optimization Core is a client-side optimization mod for Minecraft 1.12.2.

## Informações
- **Versão:** 1.4.1
- **Mod ID:** `advancedoptimizationcore`
- **Autores:** Raposito9
- **Minecraft:** 1.12.2

## Suporte
- **GitHub:** https://github.com/Dany96838/optfine_aoc

## Compatibilidade
- **Forge 1.12.2**
- **Client-side**

## Descrição
O Advanced Optimization Core melhora o desempenho de renderização por meio de otimizações conservadoras de entidades, TileEntities, partículas, efeitos visuais e oclusão por blocos. Os objetos do jogo não são removidos, descarregados ou alterados no estado do jogo/servidor.

## Opções
- Occlusion Culling
- Distância de entidades
- Distância de itens dropados
- Distância de TileEntities
- Otimização de partículas
- Otimização de efeitos visuais
- Otimização de blocos visuais
- Configuração de Players
- Distância dos Players
- Opacidade do Nick
